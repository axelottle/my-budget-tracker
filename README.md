# Budget Tracker

A simple personal budget tracker built with Next.js, React, TypeScript, and Tailwind CSS. Track income and expenses, set a monthly budget, and see where your money goes — all stored locally in the browser, no backend required.

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Browser `localStorage` for persistence (no database/backend)

## Status

🚧 Work in progress — being built incrementally, phase by phase. Currently supports:

- Dashboard with balance, income, expenses, and budget summary
- Adding, editing, and deleting transactions
- Predefined income/expense categories
- Basic form validation

Coming soon: localStorage persistence, budget progress bar, filtering/search, spending-by-category summary, and responsive polish.

## Running Locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
